# Sistema de Análise de Vendas com Python

Projeto em Python para análise de dados de vendas utilizando a biblioteca **pandas**.  
O sistema realiza a integração de diferentes tabelas (clientes, produtos e vendas) e gera relatórios úteis a partir dos dados.

---

## Funcionalidades

-  Visualização de todos os dados
-  Faturamento total
-  Faturamento por cliente
-  Produtos mais vendidos
-  Análise de compras por faixa de valor
-  Ranking de clientes
-  Relatório geral automatizado

---

## Tecnologias utilizadas

- Python
- Pandas

---

## Estrutura dos dados

O projeto utiliza três arquivos CSV:

- `clientes.csv`
- `produtos.csv`
- `vendas.csv`
